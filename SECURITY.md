# Security Policy

## Supported versions

Security fixes are applied to the current default branch. No separate release-support schedule is currently published.

## Reporting a vulnerability

Please do not publish exploitable vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled, or email [abdullahzulfiqar137@gmail.com](mailto:abdullahzulfiqar137@gmail.com) with the affected component, impact, and safe reproduction steps.

Do not send patient information, medical records, authentication tokens, connection strings, or other sensitive data.

## Healthcare data warning

This repository is a software project, not a certified healthcare service. Use synthetic data for development and demonstrations. A production operator must independently assess applicable privacy, security, regulatory, backup, access-control, and audit requirements before handling real patient data.
